# What the Project Is
This project is a JavaScript-based customer review application built using Node.js, Express, MySQL, and two custom classes where one inherits from the other. The program allows users to submit restaurant reviews, save them to a database, and view all submitted reviews on a separate page. It uses EJS for rendering, proper class structure, methods for inserting and retrieving reviews.

# Why It Was Made
The project was created for the Fundamentals of Object-Oriented Programming module as part of Skills Demo 3. Its purpose was to demonstrate understanding of OOP concepts such as inheritance, methods, data structures, selection statements, control structures, and accurate programming practices.

# How to Run It
To run the project, install Node.js and MySQL, open the FSD3 folder in a terminal, and run `npm install` if dependencies are required. Set up a MySQL database and import the table used for storing reviews. Update the database connection details in the code, then start the server by typing `node index.js`. If everything is correct, the terminal will show “App is running”, and you can open `http://localhost:3000` in your browser to submit and view reviews.
